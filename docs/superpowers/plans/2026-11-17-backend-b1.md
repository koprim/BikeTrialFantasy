# Backend B1 — Supabase foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **MANDATORY for every implementer and reviewer:** read and follow the project skill `.claude/skills/solid-clean-code/SKILL.md` (SOLID, TDD, clean code, patterns). Run jest from **PowerShell** (the bash rtk wrapper breaks jest).

**Goal:** Player data and every state-changing game action (starter, daily pack, recycle, craft, save team) move to a Supabase backend that has the final say, while the app keeps a working offline demo mode.

**Architecture:** Postgres (migrations + RLS) holds reference data, catalog and player data. Use cases live in `src/backend` (plain CommonJS, unit-tested with Jest and in-memory fakes), reuse the existing pure engine `src/engine`, and talk to Supabase through small adapters. Multi-table writes go through one Postgres function `commit_collection_change` with optimistic locking. esbuild bundles `src/backend` + `src/engine` into one generated file that thin Deno Edge Functions import (single source, no copy). The app talks to a `GameApi` interface with two implementations: `demo` (current local behaviour) and `supabase`.

**Tech Stack:** Supabase CLI (local stack on Podman, Docker fallback), Postgres/plpgsql, supabase-js v2, Deno Edge Functions, esbuild, Expo 50 / React Native, Jest, ESLint 8 + eslint-config-expo, Prettier 3, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-17-backend-supabase-design.md`

**Deliberate scope cuts (recorded, not forgotten):**
- Account saving uses the e-mail magic link only. Google/Apple linking needs provider credentials: follow-up task once the user creates them.
- Reference data (riders, competitions, results) is still read from the bundled JSON by the app; it moves online with TanStack Query in B2, when real results arrive. The server already reads catalog and competitions from Postgres.
- Sentry and scheduled backups are set up with the `prod` project (launch checklist), not in B1.

```sql
create table public.app_settings (

  value text

-- Public read, admin-only write (writes happen with the service role, which bypasses RLS).
do $$
declare t text;
begin
  foreach t in array array['seasons', 'riders', 'competitions', 'cards', 'balance', 'app_settings'] loop
    execute format('alter table public.%I enable row level security', t);
    execute format('create policy "public read" on public.%I for select to anon, authenticated using (true)', t);
    execute format('revoke insert, update, delete on public.%I from anon, authenticated', t);
  end loop;
end $$;
```

```sql
create table public.profiles (
  user_id uuid primary key references auth.users (id) on delete cascade,
  display_name text not null default 'Joueur' check (char_length(display_name) between 1 and 30),
  created_at timestamptz not null default now()
);

create table public.wallets (
  user_id uuid primary key references auth.users (id) on delete cascade,
  fragments int not null default 0 check (fragments >= 0),
  pity_e int not null default 0 check (pity_e >= 0),
  pity_l int not null default 0 check (pity_l >= 0),
  packs_opened int not null default 0 check (packs_opened >= 0),
  last_pack_date date,
  starter_given boolean not null default false,
  version int not null default 0
);

create table public.owned_cards (
  user_id uuid not null references auth.users (id) on delete cascade,
  card_id text not null references public.cards (id),
  rarity text not null check (rarity in ('C', 'R', 'E', 'L')),
  count int not null check (count >= 0),
  primary key (user_id, card_id, rarity)
);

create table public.pack_openings (
  id bigint generated always as identity primary key,
  user_id uuid not null references auth.users (id) on delete cascade,
  kind text not null check (kind in ('starter', 'daily')),
  pack_date date not null,
  cards jsonb not null,
  opened_at timestamptz not null default now(),
  unique (user_id, kind, pack_date)
);
create unique index pack_openings_one_starter on public.pack_openings (user_id) where kind = 'starter';

create table public.teams (
  user_id uuid not null references auth.users (id) on delete cascade,
  competition_id text not null references public.competitions (id),
  team jsonb not null,
  updated_at timestamptz not null default now(),
  primary key (user_id, competition_id)
);

create function public.handle_new_user() returns trigger
language plpgsql security definer set search_path = '' as $$
begin
  insert into public.profiles (user_id) values (new.id);
  insert into public.wallets (user_id) values (new.id);
  return new;
end $$;

create trigger on_auth_user_created
  after insert on auth.users
  for each row execute function public.handle_new_user();

-- Owner-only read; only the service role (Edge Functions) writes game state.
do $$
declare t text;
begin
  foreach t in array array['profiles', 'wallets', 'owned_cards', 'pack_openings', 'teams'] loop
    execute format('alter table public.%I enable row level security', t);
    execute format('create policy "owner read" on public.%I for select to authenticated using (user_id = (select auth.uid()))', t);
    execute format('revoke insert, update, delete on public.%I from anon, authenticated', t);
  end loop;
end $$;

-- Renaming is the only direct write a player may do.
create policy "owner rename" on public.profiles for update to authenticated
  using (user_id = (select auth.uid())) with check (user_id = (select auth.uid()));
grant update (display_name) on public.profiles to authenticated;
```

### Task 6: Migration — `commit_collection_change`

**Files:** Create `supabase/migrations/<ts>_commit_collection_change.sql`, `test/integration/commitCollectionChange.int.test.js`.

Contract: `commit_collection_change(p_user_id uuid, p_expected_version int, p_wallet jsonb, p_owned_deltas jsonb, p_opening jsonb default null) returns text` → `'ok' | 'conflict' | 'duplicate'`. `p_wallet` = `{fragments, pityE, pityL, packsOpened, lastPackDate, starterGiven}`; `p_owned_deltas` = `[{card_id, rarity, delta}]`; `p_opening` = `{kind, packDate, cards}` or null. A count going below zero raises (whole call rolled back).

- [ ] **Step 1: Write the failing test**
```js

const CARD = { id: 'test-rpc-card', type: 'EQUIPMENT', edition: '2026', name: 'Test', subject_id: null, rarities: ['C', 'R'], effects: [] };
```

```sql
  p_user_id uuid,
  p_expected_version int,
  p_wallet jsonb,
  p_owned_deltas jsonb,
  p_opening jsonb default null
) returns text
language plpgsql security definer set search_path = '' as $$
declare
  v_version int;
  v_expected_removals int;
  v_applied_removals int;
begin
  select version into v_version from public.wallets where user_id = p_user_id for update;
  if v_version is null then
    raise exception 'wallet not found for user %', p_user_id;
  end if;
  if v_version <> p_expected_version then
    return 'conflict';
  end if;

  if p_opening is not null then
    insert into public.pack_openings (user_id, kind, pack_date, cards)
    values (p_user_id, p_opening ->> 'kind', (p_opening ->> 'packDate')::date, p_opening -> 'cards')
    on conflict do nothing;
    if not found then
      return 'duplicate';
    end if;
  end if;

  insert into public.owned_cards as owned (user_id, card_id, rarity, count)
  select p_user_id, d.card_id, d.rarity, d.delta
  from jsonb_to_recordset(p_owned_deltas) as d (card_id text, rarity text, delta int)
  where d.delta > 0
  on conflict (user_id, card_id, rarity) do update set count = owned.count + excluded.count;

  select count(*) into v_expected_removals
  from jsonb_to_recordset(p_owned_deltas) as d (card_id text, rarity text, delta int)
  where d.delta < 0;

  update public.owned_cards as owned set count = owned.count + d.delta
  from jsonb_to_recordset(p_owned_deltas) as d (card_id text, rarity text, delta int)
  where d.delta < 0 and owned.user_id = p_user_id and owned.card_id = d.card_id and owned.rarity = d.rarity;
  get diagnostics v_applied_removals = row_count;
  if v_applied_removals <> v_expected_removals then
    raise exception 'cannot remove cards the player does not own';
  end if;

  delete from public.owned_cards where user_id = p_user_id and count = 0;

  update public.wallets set
    fragments = (p_wallet ->> 'fragments')::int,
    pity_e = (p_wallet ->> 'pityE')::int,
    pity_l = (p_wallet ->> 'pityL')::int,

    last_pack_date = (p_wallet ->> 'lastPackDate')::date,
    starter_given = (p_wallet ->> 'starterGiven')::boolean,
    version = version + 1
  where user_id = p_user_id;

  return 'ok';
end $$;
```

```js
function sqlLiteral(value) {
  if (value === null || value === undefined) return 'null';
  if (typeof value === 'number' || typeof value === 'boolean') return String(value);
  return `'${String(value).replace(/'/g, "''")}'`;
}

const jsonLiteral = (value) => `${sqlLiteral(JSON.stringify(value))}::jsonb`;
const textArray = (values) => `array[${values.map(sqlLiteral).join(', ')}]::text[]`;

function insert(table, columns, rows) {
  if (!rows.length) return '';
  const values = rows.map((row) => `  (${row.join(', ')})`).join(',\n');
  return `insert into public.${table} (${columns.join(', ')}) values\n${values};\n`;
}

const seasonRow = (season) => [sqlLiteral(season.id), sqlLiteral(season.name)];

const riderRow = (rider) => [
  sqlLiteral(rider.id), sqlLiteral(rider.name), sqlLiteral(rider.country), sqlLiteral(rider.category),
  sqlLiteral(rider.brand), sqlLiteral(rider.cote), sqlLiteral(rider.uciRank), sqlLiteral(rider.active !== false),
];

const competitionRow = (season, event) => [
  sqlLiteral(event.id), sqlLiteral(season.id), sqlLiteral(event.name), sqlLiteral(event.venue), sqlLiteral(event.country),
  sqlLiteral(event.round), sqlLiteral(event.dateFrom), sqlLiteral(event.dateTo || event.dateFrom), sqlLiteral(event.referee),
];

const cardRow = (card) => [
  sqlLiteral(card.id), sqlLiteral(card.type), sqlLiteral(card.edition), sqlLiteral(card.name),
  sqlLiteral(card.subject), textArray(card.rarities), jsonLiteral(card.effects),
];

function buildSeedSql({ seasons, riders, cards, balance }) {
  return [
    '-- GENERATED by scripts/build-sql-seed.js from src/data/seed. Do not edit.\n',
    insert('seasons', ['id', 'name'], seasons.map(seasonRow)),
    insert('riders', ['id', 'name', 'nation', 'category', 'brand', 'cote', 'uci_rank', 'active'], riders.map(riderRow)),
    insert(
      'competitions',
      ['id', 'season_id', 'name', 'venue', 'country', 'round', 'date_from', 'date_to', 'referee'],
      seasons.flatMap((season) => season.events.map((event) => competitionRow(season, event))),
    ),
    insert('cards', ['id', 'type', 'edition', 'name', 'subject_id', 'rarities', 'effects'], cards.map(cardRow)),
    insert('balance', ['version', 'data'], [[sqlLiteral(1), jsonLiteral(balance)]]),
  ].join('\n');
}
```

```js
function diffOwned(before, after) {

  return [...cardIds].flatMap((cardId) => {
```

```js
const { gameError } = require('../errors');

const MAX_ATTEMPTS = 3;

/**
 * Loads the player's collection, computes the change and commits it atomically.
 * compute(collection) returns { after, opening? }, or null when there is nothing to change; it throws a GameError to refuse.
 * A concurrent change (version conflict) triggers a fresh load and recompute.
 */
async function applyCollectionChange(wallets, userId, compute, { duplicateError = 'ALREADY_OPENED' } = {}) {
  for (let attempt = 0; attempt < MAX_ATTEMPTS; attempt += 1) {
    const { collection, version } = await wallets.load(userId);
    const change = compute(collection);
    if (!change) return collection;
    const outcome = await wallets.commit(userId, {
      expectedVersion: version,
      before: collection,
      after: change.after,
      opening: change.opening || null,
    });
    if (outcome === 'ok') return change.after;
    if (outcome === 'duplicate') throw gameError(duplicateError);
    if (outcome !== 'conflict') throw new Error(`Unexpected commit outcome: ${outcome}`);
  }
  throw gameError('BUSY');
}

module.exports = { applyCollectionChange };
```

```js
const { GameError } = require('./errors');

const CORS_HEADERS = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
  'Access-Control-Allow-Methods': 'POST, OPTIONS',
};

function json(status, body) {
  return new Response(JSON.stringify(body), { status, headers: { ...CORS_HEADERS, 'Content-Type': 'application/json' } });
}

const MALFORMED = Symbol('malformed');

async function readBody(request) {
  const text = await request.text();
  if (!text) return {};
  try {
    return JSON.parse(text);
  } catch {
    return MALFORMED;
  }
}

function errorResponse(error, logError) {
  if (error instanceof GameError) return json(error.status, { error: error.code, details: error.details });
  logError(error);
  return json(500, { error: 'INTERNAL' });
}

function makeHttpHandler({ authenticate, action, logError = console.error }) {
  return async (request) => {
    if (request.method === 'OPTIONS') return new Response(null, { status: 204, headers: CORS_HEADERS });
    if (request.method !== 'POST') return json(405, { error: 'METHOD_NOT_ALLOWED' });
    try {
      const userId = await authenticate(request);
      const body = await readBody(request);
      if (body === MALFORMED) return json(400, { error: 'INVALID_INPUT' });
      return json(200, await action(userId, body));
    } catch (error) {
      return errorResponse(error, logError);
    }
  };
}

module.exports = { makeHttpHandler };
```

```js
// Offline demo backend: the local reducer is the authority and the device storage is the database.
export function createDemoApi({ storage = { loadState, saveState } } = {}) {
  let state = initialState;

  async function apply(action, toPatch, refusal = 'NOT_ALLOWED') {
    const next = gameReducer(state, action);
    if (next === state) return { ok: false, error: refusal };
    state = next;
    await storage.saveState(state);
```

```js
const { toWalletState, toPicks } = require('../../backend/mappers');

const CACHE_KEY = 'sfbt:supabase-cache:v1';

function unwrap({ data, error }) {
  if (error) throw error;
  return data;
}

async function invokeFunction(client, name, body) {
  const { data, error } = await client.functions.invoke(name, { body: body || {} });
  if (!error) return { ok: true, data };
  const payload = error.context && typeof error.context.json === 'function' ? await error.context.json().catch(() => null) : null;
  return { ok: false, error: (payload && payload.error) || 'NETWORK', details: payload ? payload.details : undefined };
}

// Server-backed GameApi: reads go straight to Postgres (RLS), state changes go through Edge Functions.
function createSupabaseApi({ client, storage, allowSimulatedDate = false, emailRedirectTo }) {
  async function currentUser() {
    const { data } = await client.auth.getSession();
    if (data.session) return data.session.user;
    const { data: signedIn, error } = await client.auth.signInAnonymously();
    if (error) throw error;
    return signedIn.user;
  }

  async function fetchPlayerState(user) {
    const byUser = (table, columns) => client.from(table).select(columns).eq('user_id', user.id);
    const [profile, wallet, owned, teams, setting] = await Promise.all([
      byUser('profiles', 'display_name').single().then(unwrap),
      byUser('wallets', '*').single().then(unwrap),
      byUser('owned_cards', 'card_id, rarity, count').then(unwrap),
      byUser('teams', 'competition_id, team').then(unwrap),
      client.from('app_settings').select('value').eq('key', 'simulated_date').maybeSingle().then(unwrap),
    ]);
    return {
      player: { name: profile.display_name },
      picks: toPicks(teams),
      collection: toWalletState(wallet, owned).collection,
      simulatedDate: allowSimulatedDate && setting ? setting.value : null,
    };
  }

  const collectionAction = (name) => async (body) => {
    const result = await invokeFunction(client, name, body);
    return result.ok ? { ok: true, patch: { collection: result.data.collection } } : result;
  };

  return {
    features: { simulatedDate: allowSimulatedDate, reset: false, account: true },
    async load() {
      try {
        const state = await fetchPlayerState(await currentUser());
        await storage.setItem(CACHE_KEY, JSON.stringify(state));
        return state;
      } catch (error) {
        const cached = await storage.getItem(CACHE_KEY);
        if (cached) return { ...JSON.parse(cached), offline: true };
        throw error;
      }
    },
    openStarter: collectionAction('open-starter'),
    openDailyPack: collectionAction('open-daily-pack'),
    recycle: collectionAction('recycle'),
    craft: collectionAction('craft'),
    async saveTeam({ eventId, team }) {
      const result = await invokeFunction(client, 'save-team', { competitionId: eventId, team });
      if (!result.ok) return result;
      return { ok: true, patch: (state) => ({ picks: { ...state.picks, [eventId]: result.data.team } }) };
    },
    async setName(name) {
      const user = await currentUser();
      const { error } = await client.from('profiles').update({ display_name: name }).eq('user_id', user.id);
      return error ? { ok: false, error: 'NETWORK' } : { ok: true, patch: { player: { name } } };
    },
    async setSimulatedDate(date) {
      const result = await invokeFunction(client, 'set-simulated-date', { date });
      if (!result.ok) return result;
      return { ok: true, patch: { simulatedDate: result.data.simulatedDate, collection: result.data.collection } };
    },
    async reset() {
      return { ok: false, error: 'NOT_AVAILABLE' };
    },
    async account() {
      const { data } = await client.auth.getUser();
      if (!data.user) return null;
      return { isAnonymous: Boolean(data.user.is_anonymous), email: data.user.email || null, pendingEmail: data.user.new_email || null };
    },
    async saveAccount(email) {
      const { error } = await client.auth.updateUser({ email }, { emailRedirectTo });
      return error ? { ok: false, error: 'ACCOUNT_SAVE_FAILED', details: error.message } : { ok: true, patch: {} };
    },
    // Existing saved account on a new browser: magic link; the guest session of this browser is replaced on return.
    async signIn(email) {
      const { error } = await client.auth.signInWithOtp({ email, options: { shouldCreateUser: false, emailRedirectTo } });
      return error ? { ok: false, error: 'SIGN_IN_FAILED', details: error.message } : { ok: true, patch: {} };
    },
  };
}

module.exports = { createSupabaseApi };
```

```js
import React, { createContext, useContext, useEffect, useMemo, useReducer, useState } from 'react';
import { Text } from 'react-native';
import { createApi } from '../data/api';
// ...existing data/engine imports used by useNow/useScoring...
export { gameReducer, initialState } from './gameReducer';

function clientReducer(state, action) {
  switch (action.type) {
    case 'LOADED':
      return action.payload;
    case 'PATCH': {
      const patch = typeof action.payload === 'function' ? action.payload(state) : action.payload;
      return { ...state, ...patch };
    }
    default:
      return state;
  }
}

let defaultApi = null;
const getDefaultApi = () => defaultApi || (defaultApi = createApi());

const GameContext = createContext(null);

export function GameProvider({ api: injectedApi, children }) {
  const api = useMemo(() => injectedApi || getDefaultApi(), [injectedApi]);
  const [state, dispatch] = useReducer(clientReducer, null);
  const [loadFailed, setLoadFailed] = useState(false);

  useEffect(() => {
    let active = true;
    api.load()
      .then((loaded) => active && dispatch({ type: 'LOADED', payload: loaded }))
      .catch(() => active && setLoadFailed(true));
    return () => { active = false; };
  }, [api]);

  const actions = useMemo(() => {
    const run = (call) => async (...args) => {
      const result = await call(...args);
      if (result.ok) dispatch({ type: 'PATCH', payload: result.patch });
      return result;
    };
    return {
      openStarter: run(api.openStarter), openDailyPack: run(api.openDailyPack), recycle: run(api.recycle), craft: run(api.craft),
      saveTeam: run(api.saveTeam), setName: run(api.setName), setSimulatedDate: run(api.setSimulatedDate), reset: run(api.reset),
      saveAccount: run(api.saveAccount), signIn: run(api.signIn), account: api.account,
    };
  }, [api]);

  if (loadFailed) return <Text accessibilityRole="alert">Connexion impossible. Vérifie ta connexion puis relance l'application.</Text>;
  if (!state) return null;
  return <GameContext.Provider value={{ state, actions, features: api.features }}>{children}</GameContext.Provider>;
}

export function useGame() {
  const context = useContext(GameContext);
  if (!context) throw new Error('useGame must be used within GameProvider');
  return context;
}
```

- [ ] **Step 7: `src/screens/AccountScreen.js`**
```js
import React, { useEffect, useState } from 'react';
import { View, Text, TextInput, Pressable, StyleSheet } from 'react-native';
import { useGame } from '../state/GameContext';
import { errorMessage } from '../ui/errorMessages';
import { colors } from '../ui/theme';

const EMAIL_PATTERN = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

export default function AccountScreen() {
  const { actions } = useGame();
  const [account, setAccount] = useState(undefined);
  const [email, setEmail] = useState('');
  const [message, setMessage] = useState(null);

  useEffect(() => {
    actions.account().then(setAccount);
  }, [actions]);

  if (account === undefined) return null;
  if (account && !account.isAnonymous) {
    return <View style={styles.page}><Text style={styles.text}>Compte sauvegardé : {account.email}</Text></View>;
  }

  const address = email.trim();
  const save = async () => {
    const result = await actions.saveAccount(address);
    setMessage(result.ok ? `Un lien de confirmation a été envoyé à ${address}. Ouvre-le pour terminer.` : errorMessage(result.error));
  };
  const signIn = async () => {
    const result = await actions.signIn(address);
    setMessage(result.ok ? `Un lien de connexion a été envoyé à ${address}. La partie invitée de ce navigateur sera remplacée.` : errorMessage(result.error));
  };

  return (
    <View style={styles.page}>
      <Text style={styles.text}>
        Tu joues avec un compte invité, lié à ce navigateur ou à cet appareil. Sauvegarde-le pour retrouver ta collection partout.
      </Text>
      {account && account.pendingEmail ? <Text style={styles.text}>Confirmation en attente pour {account.pendingEmail}.</Text> : null}
      <TextInput accessibilityLabel="Adresse e-mail" value={email} onChangeText={setEmail} autoCapitalize="none" keyboardType="email-address" style={styles.input} />
      <Pressable accessibilityRole="button" disabled={!EMAIL_PATTERN.test(address)} onPress={save} style={styles.cta}>
        <Text style={styles.ctaText}>Sauvegarder mon compte</Text>
      </Pressable>
      <Pressable accessibilityRole="button" disabled={!EMAIL_PATTERN.test(address)} onPress={signIn} style={styles.secondary}>
        <Text style={styles.text}>J'ai déjà un compte</Text>
      </Pressable>
      {message ? <Text accessibilityRole="alert" style={styles.text}>{message}</Text> : null}
    </View>
  );
}

const styles = StyleSheet.create({
  page: { padding: 16, gap: 12 },
  text: { color: colors.text },
  input: { borderWidth: 1, borderColor: colors.border, borderRadius: 8, padding: 10, color: colors.text, backgroundColor: colors.surface },
  cta: { backgroundColor: colors.primary, borderRadius: 8, padding: 12, alignItems: 'center' },
  ctaText: { color: '#fff', fontWeight: '700' },
  secondary: { padding: 12, alignItems: 'center' },
});
```
