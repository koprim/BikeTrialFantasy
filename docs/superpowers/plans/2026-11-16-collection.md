# Collection, packs quotidiens et effets — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Players own cards (pilot, technique, equipment, referee) in four rarities, open one pack a day, recycle and craft, and compose teams from their collection; card effects add points on top of the existing `position × cote` score.

**Architecture:** Pure CommonJS engine modules (`rarity`, `effects`, `catalog`, `team`, `scoring`, `collection`) driven by two data files (`cards.json` generated by the seed script, `balance.json` hand-written). Game state gains a `collection`; teams become card teams `{ slots, equipment, referee }`. Old rider-id teams and old `2026-27-rN` event ids are converted on load by `normalizeTeam` / `migrateSave`. UI adds a 🃏 Collection tab (grid, pack reveal, card detail) and rewrites Compose.

**Tech Stack:** Expo 50, React Native 0.73 + react-native-web, @react-navigation 6, AsyncStorage, Jest (jest-expo), @testing-library/react-native.

**Spec:** `docs/superpowers/specs/2026-11-16-collection-design.md`

**Conventions:**
- Engine files (`src/engine/*`, `src/state/selectors.js`, `src/state/migrate.js`) are CommonJS (`require` / `module.exports`). React files are ESM.
- Run Jest from **PowerShell** (the bash rtk wrapper breaks it): `npx jest <path>`.
- Dates are `'YYYY-MM-DD'` strings compared lexically.
- Small additions to the spec's state shape: `collection.packsOpened` (seeds the daily RNG) and `collection.lastPack` (cards shown on the reveal screen).

```js
function hashString(s) {
  let h = 2166136261;
```

```js
// Declarative card effects: { description, trigger, reward }. Pure functions only.
const TRIGGERS = ['ALWAYS', 'RIDER_TOP_N', 'RIDER_DID_TECHNIQUE', 'RIDER_CLEAN_MIN',
  'NATION_COUNT_IN_TOP', 'CATEGORY_WINNER_NATION', 'TEAM_BRAND_COUNT', 'CATEGORY_WINNER_OUTSIDER'];
const REWARDS = ['FLAT_POINTS', 'RIDER_MULTIPLIER', 'CATEGORY_MULTIPLIER', 'TEAM_MULTIPLIER'];
const RIDER_TRIGGERS = ['RIDER_TOP_N', 'RIDER_DID_TECHNIQUE', 'RIDER_CLEAN_MIN'];

function winnerOf(event, category, ridersById) {
  const order = (event.results || {})[category] || [];
  return ridersById[order[0]] || null;
}

// ctx = { event, ridersById, riderId (rider the card acts on, or null), teamRiderIds }
function evaluateTrigger(trigger, ctx) {
  const { event, ridersById, riderId, teamRiderIds } = ctx;
  const results = event.results || {};
  const stats = riderId ? (event.stats || {})[riderId] : null;
  switch (trigger.type) {
    case 'ALWAYS':
      return true;
    case 'RIDER_TOP_N': {
      const rider = riderId && ridersById[riderId];
      const order = rider && results[rider.category];
      if (!order) return false;
      const idx = order.indexOf(riderId);
      return idx >= 0 && idx < trigger.n;
    }
    case 'RIDER_DID_TECHNIQUE':
      return !!stats && stats.techniques.includes(trigger.technique);
    case 'RIDER_CLEAN_MIN':
      return !!stats && stats.cleanSections >= trigger.min;
    case 'NATION_COUNT_IN_TOP': {
      const top = (results[trigger.category] || []).slice(0, trigger.top);
      return top.filter((id) => ridersById[id] && ridersById[id].country === trigger.nation).length >= trigger.min;
    }
    case 'CATEGORY_WINNER_NATION': {
      const w = winnerOf(event, trigger.category, ridersById);
      return !!w && w.country === trigger.nation;
    }
    case 'TEAM_BRAND_COUNT':
      return teamRiderIds.filter((id) => ridersById[id] && ridersById[id].brand === trigger.brand).length >= trigger.min;
    case 'CATEGORY_WINNER_OUTSIDER': {
      const w = winnerOf(event, trigger.category, ridersById);
      return !!w && w.cote >= trigger.minCote;
    }
    default:
      return false;
  }
}

function scaledValue(reward, rarity, balance) {
  return reward.value * balance.rarityMultiplier[rarity];
}

function formatValue(reward, rarity, balance) {
  const v = scaledValue(reward, rarity, balance);
  return reward.type === 'FLAT_POINTS' ? String(Math.round(v)) : `${Math.round(v * 100)} %`;
}

function describeEffect(effect, rarity, balance) {
  return effect.description.split('{value}').join(formatValue(effect.reward, rarity, balance));
}

module.exports = { TRIGGERS, REWARDS, RIDER_TRIGGERS, evaluateTrigger, scaledValue, describeEffect };
```

```js
const { RARITIES } = require('./rarity');
const { TRIGGERS, REWARDS, RIDER_TRIGGERS } = require('./effects');

const CARD_TYPES = ['PILOT', 'TECHNIQUE', 'EQUIPMENT', 'REFEREE'];

// Returns a list of human-readable errors; [] means the catalog is usable.
function validateCatalog(cards, ridersById) {
  const errors = [];
  const seen = new Set();
  cards.forEach((c) => {
    const at = c.id || '(sans id)';
    if (!c.id || seen.has(c.id)) errors.push(`${at} : id manquant ou en double`);
    seen.add(c.id);
    if (!CARD_TYPES.includes(c.type)) errors.push(`${at} : type inconnu ${c.type}`);
    if (!c.name) errors.push(`${at} : nom manquant`);
    const ranks = (c.rarities || []).map((r) => RARITIES.indexOf(r));
    if (!ranks.length || ranks.some((r, k) => r < 0 || (k > 0 && r <= ranks[k - 1]))) {
      errors.push(`${at} : raretés invalides (non vides, dans l'ordre C, R, E, L)`);
    }
    if (c.type === 'PILOT' && !ridersById[c.subject]) errors.push(`${at} : pilote inconnu ${c.subject}`);
    const teamCard = c.type === 'EQUIPMENT' || c.type === 'REFEREE';
    (c.effects || []).forEach((e, k) => {
      const where = `${at} effet ${k + 1}`;
      if (!e.description || typeof e.description !== 'string') errors.push(`${where} : description manquante`);
      if (!e.trigger || !TRIGGERS.includes(e.trigger.type)) errors.push(`${where} : déclencheur inconnu`);
      if (!e.reward || !REWARDS.includes(e.reward.type)) errors.push(`${where} : récompense inconnue`);
      if (teamCard && e.trigger && RIDER_TRIGGERS.includes(e.trigger.type)) errors.push(`${where} : déclencheur pilote sur une carte d'équipe`);
      if (teamCard && e.reward && e.reward.type === 'RIDER_MULTIPLIER') errors.push(`${where} : multiplicateur pilote sur une carte d'équipe`);
    });
  });
  return errors;
}

module.exports = { CARD_TYPES, validateCatalog };
```

```js
function pilotCardId(edition, riderId) { return `pilot-${edition}-${riderId}`; }

function emptyTeam() { return { slots: {}, equipment: [], referee: null }; }

function cardTeamFromRiders(riderTeam, edition) {
  const slots = {};
  SLOTS.forEach((s) => {
    const riderId = riderTeam && riderTeam[s.id];
    if (riderId) slots[s.id] = { cardId: pilotCardId(edition, riderId), rarity: 'C', techniques: [] };
  });
  return { slots, equipment: [], referee: null };
}

// Old saves store { senior26: riderId, … }: convert them to Common pilot cards.
function normalizeTeam(team, edition) {
  if (!team) return null;
  return 'slots' in team ? team : cardTeamFromRiders(team, edition);
}

function teamRiderIds(team, cardsById) {
  return SLOTS.map((s) => team.slots[s.id])
    .filter(Boolean)
    .map((e) => cardsById[e.cardId])
    .filter(Boolean)
    .map((c) => c.subject);
}

function ownsCard(owned, ref) {
  return !!owned[ref.cardId] && (owned[ref.cardId][ref.rarity] || 0) > 0;
}

// deps = { cardsById, ridersById, owned, balance }
function validateCardTeam(team, { cardsById, ridersById, owned, balance }) {
  const errors = [];
  const used = new Set();
  const riderIds = [];
  const useCard = (ref, type, where) => {
    const card = cardsById[ref.cardId];
    if (!card || card.type !== type) { errors.push(`${where} : carte invalide.`); return null; }
    if (!card.rarities.includes(ref.rarity)) { errors.push(`${where} : rareté indisponible.`); return null; }
    if (!ownsCard(owned, ref)) errors.push(`${where} : carte non possédée.`);
    const key = `${ref.cardId}:${ref.rarity}`;
    if (used.has(key)) errors.push(`${where} : carte déjà utilisée.`);
    used.add(key);
    return card;
  };
  SLOTS.forEach((slot) => {
    const entry = team.slots[slot.id];
    if (!entry) { errors.push(`${slot.label} : emplacement vide.`); return; }
    const card = useCard(entry, 'PILOT', slot.label);
    if (!card) return;
    const rider = ridersById[card.subject];
    if (!rider || rider.category !== slot.category) errors.push(`${slot.label} : mauvaise catégorie.`);
    else if (riderIds.includes(rider.id)) errors.push(`${slot.label} : pilote déjà dans l'équipe.`);
    else riderIds.push(rider.id);
    const techniques = entry.techniques || [];
    if (techniques.length > balance.slots.techniquesByPilotRarity[entry.rarity]) errors.push(`${slot.label} : trop de techniques.`);
    techniques.forEach((t) => useCard(t, 'TECHNIQUE', slot.label));
  });
  const equipment = team.equipment || [];
  if (equipment.length > balance.slots.equipment) errors.push('Trop d\'équipements.');
  equipment.forEach((e) => useCard(e, 'EQUIPMENT', 'Équipement'));
  if (team.referee) useCard(team.referee, 'REFEREE', 'Arbitre');
  return { valid: errors.length === 0, errors };
}

  };
```

```js
    const rider = card && ridersById[card.subject];
    const position = rider ? positionOf(rider.id, rider.category, event.results) : null;
    rows.push({

      riderId: rider ? rider.id : null, category: rider ? rider.category : null, name: rider ? rider.name : null,

  });

  const base = rows.map((r) => r.points);
  ofType('RIDER_MULTIPLIER').filter((f) => f.riderId).forEach((f) => {
    const i = rows.findIndex((r) => r.riderId === f.riderId);
```

```js
const { rarityRank, atLeast } = require('./rarity');
const { makeRng, hashString } = require('./rng');

function emptyCollection() {
  return { owned: {}, fragments: 0, pity: { E: 0, L: 0 }, packsOpened: 0, lastPackDate: null, starterGiven: false, lastPack: [] };
}

function countOf(collection, cardId, rarity) {
  return (collection.owned[cardId] || {})[rarity] || 0;
}

function addCard(owned, cardId, rarity) {
  const cur = owned[cardId] || {};
  return { ...owned, [cardId]: { ...cur, [rarity]: (cur[rarity] || 0) + 1 } };
}

function pickWeighted(weights, rng) {
  const entries = Object.entries(weights);
  const total = entries.reduce((sum, [, w]) => sum + w, 0);
  let x = rng() * total;
  for (const [key, w] of entries) { x -= w; if (x < 0) return key; }
  return entries[entries.length - 1][0];
}

// type null = any type. Prefers cards that exist at this rarity; else the closest lower rarity.
function drawCard(cards, type, rarity, rng) {
  const pool = type ? cards.filter((c) => c.type === type) : cards;
  const exact = pool.filter((c) => c.rarities.includes(rarity));
  if (exact.length) return { card: exact[Math.floor(rng() * exact.length)], rarity };
  const card = pool[Math.floor(rng() * pool.length)];
  const lower = card.rarities.filter((r) => rarityRank(r) <= rarityRank(rarity));
  return { card, rarity: lower.length ? lower[lower.length - 1] : card.rarities[0] };
}

function receive(collection, drawn) {
  let owned = collection.owned;
  const lastPack = drawn.map(({ card, rarity }) => {
    const isNew = !((owned[card.id] || {})[rarity]);
    owned = addCard(owned, card.id, rarity);
    return { cardId: card.id, rarity, isNew };
  });
  return { owned, lastPack };
}

function openPack(collection, { cards, balance }, rng) {
  const { size, guaranteedMinRarity, odds, typeWeights } = balance.pack;
  const needL = collection.pity.L + 1 >= balance.pity.L;
  const needE = collection.pity.E + 1 >= balance.pity.E;
  const drawn = [];
  for (let i = 0; i < size; i++) {
    const guaranteed = i === size - 1;
    let rarity = pickWeighted(odds, rng);
    if (guaranteed && !atLeast(rarity, guaranteedMinRarity)) rarity = guaranteedMinRarity;
    let forced = false;
    if (guaranteed && needL) { rarity = 'L'; forced = true; } else if (guaranteed && needE && !atLeast(rarity, 'E')) { rarity = 'E'; forced = true; }
    drawn.push(drawCard(cards, forced ? null : pickWeighted(typeWeights, rng), rarity, rng));
  }
  const { owned, lastPack } = receive(collection, drawn);
  const gotE = drawn.some((d) => atLeast(d.rarity, 'E'));
  const gotL = drawn.some((d) => d.rarity === 'L');
  return {
    ...collection, owned, lastPack, packsOpened: collection.packsOpened + 1,
    pity: { E: gotE ? 0 : collection.pity.E + 1, L: gotL ? 0 : collection.pity.L + 1 },
  };
}

function canOpenDaily(collection, now) {
  return !collection.lastPackDate || collection.lastPackDate < now;
}

// Packs do not pile up: one per calendar day, seeded by the date and the pack count.
function openDailyPack(collection, now, deps) {
  if (!canOpenDaily(collection, now)) return collection;
  const rng = makeRng(hashString(`${now}#${collection.packsOpened}`));
  return { ...openPack(collection, deps, rng), lastPackDate: now };
}

function openStarter(collection, { cards, ridersById }, rng) {
  if (collection.starterGiven) return collection;
  const take = (list, n) => {
    const pool = [...list];
    const out = [];
    while (out.length < n && pool.length) out.push(pool.splice(Math.floor(rng() * pool.length), 1)[0]);
    return out;
  };
  const commons = cards.filter((c) => c.rarities.includes('C'));
  const pilotsOf = (cat) => commons.filter((c) => c.type === 'PILOT' && ridersById[c.subject]
    && ridersById[c.subject].active !== false && ridersById[c.subject].category === cat);
  const chosen = [
    ...['SENIOR_26', 'JUNIOR_26', 'SENIOR_20', 'JUNIOR_20'].flatMap((cat) => take(pilotsOf(cat), 1)),
    ...take(pilotsOf('ELITE_WOMEN'), 2),
    ...take(commons.filter((c) => c.type === 'TECHNIQUE'), 3),
    ...take(commons.filter((c) => c.type === 'EQUIPMENT'), 1),
  ];
  const { owned, lastPack } = receive(collection, chosen.map((card) => ({ card, rarity: 'C' })));
  return { ...collection, owned, lastPack, starterGiven: true };
}

function recycle(collection, cardId, rarity, balance) {
  const n = countOf(collection, cardId, rarity);
  if (n < 2) return collection;
  return {
    ...collection,
    owned: { ...collection.owned, [cardId]: { ...collection.owned[cardId], [rarity]: n - 1 } },
    fragments: collection.fragments + balance.fragments.perDuplicate[rarity],
  };
}

function craft(collection, card, rarity, balance) {
  const cost = balance.fragments.craftCost[rarity];
  if (!card || !card.rarities.includes(rarity) || collection.fragments < cost) return collection;
  return { ...collection, owned: addCard(collection.owned, card.id, rarity), fragments: collection.fragments - cost };
}

function ownedRefs(collection, cards, filter) {
  return cards.filter(filter).flatMap((card) => card.rarities
    .filter((r) => countOf(collection, card.id, r) > 0)
```

```js
const { normalizeTeam } = require('../engine/team');

const renameEventId = (id) => id.replace(/^2026-27-/, '2026-');

// Brings any saved state to the current shape, or returns null when it cannot be used.
function migrateSave(saved, { edition, demoCollection }) {
  if (!saved || 'currentIndex' in saved || !saved.picks) return null;
  const picks = {};
  Object.entries(saved.picks).forEach(([id, team]) => { picks[renameEventId(id)] = normalizeTeam(team, edition); });
  let collection = saved.collection;
  if (!collection) {
    // Saves from before the collection: start from the demo collection and own every pilot already played.
    collection = JSON.parse(JSON.stringify(demoCollection));
    Object.values(picks).forEach((team) => Object.values(team.slots).forEach((e) => {
      const counts = collection.owned[e.cardId] || (collection.owned[e.cardId] = {});
      counts[e.rarity] = Math.max(counts[e.rarity] || 0, 1);
    }));
  }
  return { ...saved, picks, collection };
}
```

```js
function gameReducer(state, action) {
  switch (action.type) {
    case 'SAVE_TEAM': {
      const { eventId, team, now } = action.payload;
      const event = EVENTS_BY_ID[eventId];
      if (!event || eventStatus(event, now) !== 'open') return state;
      return { ...state, picks: { ...state.picks, [eventId]: team } };
    }
    case 'SET_NAME':
      return { ...state, player: { name: action.payload.name } };
    case 'SET_SIMULATED_DATE':
      return { ...state, simulatedDate: action.payload.date };
    case 'OPEN_STARTER':
      return withCollection(state, openStarter(state.collection, { cards: CARDS, ridersById: RIDERS_BY_ID },
        makeRng(hashString(`starter#${state.player.name}`))));
    case 'OPEN_DAILY_PACK':
      return withCollection(state, openDailyPack(state.collection, action.payload.now, { cards: CARDS, balance: BALANCE }));
    case 'RECYCLE':
      return withCollection(state, recycle(state.collection, action.payload.cardId, action.payload.rarity, BALANCE));
    case 'CRAFT':
      return withCollection(state, craft(state.collection, CARDS_BY_ID[action.payload.cardId], action.payload.rarity, BALANCE));
    case 'RESET':
      return initialState;
    case 'HYDRATE': {
      const migrated = migrateSave(action.payload, { edition: EDITION, demoCollection: DEMO_PLAYER.collection });
      return migrated ? { ...state, ...migrated } : state;
    }
```

```js
// Simulates players opening one pack a day (recycling duplicates, crafting the cheapest missing card)
// and prints the median day at which each rarity is 50% and 100% complete.
// Usage: npm run sim:economy   (PLAYERS=200 npm run sim:economy for a quicker run)
const cards = require('../src/data/seed/cards.json');
const balance = require('../src/data/seed/balance.json');
const { emptyCollection, openPack, recycle, craft, countOf } = require('../src/engine/collection');
const { RARITIES, RARITY_LABELS } = require('../src/engine/rarity');
const { makeRng } = require('../src/engine/rng');

const PLAYERS = Number(process.env.PLAYERS || 1000);
const DAYS = Number(process.env.DAYS || 365);
const totals = Object.fromEntries(RARITIES.map((r) => [r, cards.filter((c) => c.rarities.includes(r)).length]));

const ownedAt = (col, r) => cards.filter((c) => c.rarities.includes(r) && countOf(col, c.id, r) > 0).length;

function cheapestMissing(col) {
  for (const r of RARITIES) {
    const card = cards.find((c) => c.rarities.includes(r) && countOf(col, c.id, r) === 0);
    if (card) return { card, rarity: r };
  }
  return null;
}

function simulatePlayer(seed) {
  const rng = makeRng(seed);
  let col = emptyCollection();
  const reached = Object.fromEntries(RARITIES.map((r) => [r, { half: null, full: null }]));
  for (let day = 1; day <= DAYS; day++) {
    col = openPack(col, { cards, balance }, rng);
    col.lastPack.forEach(({ cardId, rarity }) => { col = recycle(col, cardId, rarity, balance); });
    let target = cheapestMissing(col);
    while (target && col.fragments >= balance.fragments.craftCost[target.rarity]) {
      col = craft(col, target.card, target.rarity, balance);
      target = cheapestMissing(col);
    }
    RARITIES.forEach((r) => {
      const n = ownedAt(col, r);
      if (reached[r].half === null && n >= totals[r] / 2) reached[r].half = day;
      if (reached[r].full === null && n >= totals[r]) reached[r].full = day;
    });
  }
  return reached;
}

function median(values) {
  const sorted = values.map((v) => (v === null ? Infinity : v)).sort((a, b) => a - b);
  const m = sorted[Math.floor(sorted.length / 2)];
  return m === Infinity ? `> ${DAYS}` : String(m);
}

const runs = Array.from({ length: PLAYERS }, (_, i) => simulatePlayer(i + 1));
console.log(`${PLAYERS} joueurs, ${DAYS} jours, 1 pack/jour, ${cards.length} cartes`);
console.log('Rareté      | cartes | 50 % (jours) | 100 % (jours)');
RARITIES.forEach((r) => {
  const half = median(runs.map((x) => x[r].half));
  const full = median(runs.map((x) => x[r].full));
  console.log(`${RARITY_LABELS[r].padEnd(11)} | ${String(totals[r]).padStart(6)} | ${half.padStart(12)} | ${full.padStart(13)}`);
});
```

```jsx
import { useGame, useNow } from '../state/GameContext';
import { CARDS, CARDS_BY_ID, RIDERS_BY_ID, EVENTS_BY_ID, BALANCE, EDITION } from '../data/index';
import { SLOTS, emptyTeam, normalizeTeam, validateCardTeam } from '../engine/team';
import { ownedRefs } from '../engine/collection';
import { describeEffect } from '../engine/effects';
import { RARITY_LABELS } from '../engine/rarity';
import { eventStatus } from '../engine/calendar';
import { colors, space, radius } from '../ui/theme';

const refLabel = (ref) => `${CARDS_BY_ID[ref.cardId]?.name ?? '?'} · ${RARITY_LABELS[ref.rarity]}`;
const sameRef = (a, b) => a.cardId === b.cardId && a.rarity === b.rarity;
const PICKER_TITLES = { technique: 'Technique', equipment: 'Équipement', referee: 'Arbitre' };

export default function ComposeScreen({ navigation, route }) {
  const { state, dispatch } = useGame();
  const now = useNow();
  const event = EVENTS_BY_ID[route.params.eventId];
  const [team, setTeam] = useState(normalizeTeam(state.picks[event.id], EDITION) || emptyTeam());
  const [picker, setPicker] = useState(null); // { kind: 'pilot' | 'technique' | 'equipment' | 'referee', slot? }

  const result = validateCardTeam(team, { cardsById: CARDS_BY_ID, ridersById: RIDERS_BY_ID, owned: state.collection.owned, balance: BALANCE });
  const techLimit = (entry) => BALANCE.slots.techniquesByPilotRarity[entry.rarity];

  function options() {
    if (!picker) return [];
    const types = { pilot: 'PILOT', technique: 'TECHNIQUE', equipment: 'EQUIPMENT', referee: 'REFEREE' };
    return ownedRefs(state.collection, CARDS, (c) => c.type === types[picker.kind]
      && (picker.kind !== 'pilot' || RIDERS_BY_ID[c.subject]?.category === picker.slot.category));
  }

  function choose(option) {
    const ref = { cardId: option.cardId, rarity: option.rarity };
    setTeam((t) => {
      if (picker.kind === 'pilot') {
        const prev = t.slots[picker.slot.id];
        const techniques = (prev ? prev.techniques : []).slice(0, techLimit(ref));
        return { ...t, slots: { ...t.slots, [picker.slot.id]: { ...ref, techniques } } };
      }
      if (picker.kind === 'technique') {
        const entry = t.slots[picker.slot.id];
        return { ...t, slots: { ...t.slots, [picker.slot.id]: { ...entry, techniques: [...entry.techniques, ref] } } };
      }
      if (picker.kind === 'equipment') return { ...t, equipment: [...t.equipment, ref] };
      return { ...t, referee: ref };
    });
    setPicker(null);
  }

  const removeTechnique = (slotId, ref) => setTeam((t) => ({
    ...t, slots: { ...t.slots, [slotId]: { ...t.slots[slotId], techniques: t.slots[slotId].techniques.filter((x) => !sameRef(x, ref)) } },
  }));
  const removeEquipment = (ref) => setTeam((t) => ({ ...t, equipment: t.equipment.filter((x) => !sameRef(x, ref)) }));

  function save() {
    dispatch({ type: 'SAVE_TEAM', payload: { eventId: event.id, team, now } });
    navigation.popToTop();
  }

  if (eventStatus(event, now) !== 'open') {
    return <View style={styles.closed}><Text style={styles.closedText}>Composition fermée</Text></View>;
  }

  const chip = (ref, onPress) => (
    <Pressable key={`${ref.cardId}:${ref.rarity}`} onPress={onPress} style={styles.chip} accessibilityRole="button" accessibilityLabel={`Retirer ${refLabel(ref)}`}>
      <Text style={styles.chipText}>{refLabel(ref)} ✕</Text>
    </Pressable>
  );

  return (
    <View style={styles.container}>
      <ScrollView contentContainerStyle={{ gap: space.sm, padding: space.md }}>
        {SLOTS.map((slot) => {
          const entry = team.slots[slot.id];
          const rider = entry ? RIDERS_BY_ID[CARDS_BY_ID[entry.cardId]?.subject] : null;
          return (
            <View key={slot.id} style={styles.slot}>
              <Pressable onPress={() => setPicker({ kind: 'pilot', slot })} accessibilityRole="button">
                <Text style={styles.slotLabel}>{slot.label}</Text>
                {entry
                  ? <Text style={styles.slotRider}>{refLabel(entry)}{rider ? ` · ×${rider.cote.toFixed(1)}` : ''}</Text>
                  : <Text style={styles.slotEmpty}>Choisir un pilote…</Text>}
              </Pressable>
              {entry && (
                <View style={styles.chips}>
                  {entry.techniques.map((t) => chip(t, () => removeTechnique(slot.id, t)))}
                  {entry.techniques.length < techLimit(entry) && (
                    <Pressable onPress={() => setPicker({ kind: 'technique', slot })} style={styles.add} accessibilityRole="button">
                      <Text style={styles.addText}>+ Technique ({entry.techniques.length}/{techLimit(entry)})</Text>
                    </Pressable>
                  )}
                </View>
              )}
            </View>
          );
        })}

        <Text style={styles.section}>Équipe</Text>
        <View style={styles.slot}>
          <Text style={styles.slotLabel}>Équipements ({team.equipment.length}/{BALANCE.slots.equipment})</Text>
          <View style={styles.chips}>
            {team.equipment.map((e) => chip(e, () => removeEquipment(e)))}
            {team.equipment.length < BALANCE.slots.equipment && (
              <Pressable onPress={() => setPicker({ kind: 'equipment' })} style={styles.add} accessibilityRole="button">
                <Text style={styles.addText}>+ Équipement</Text>
              </Pressable>
            )}
          </View>
        </View>
        <View style={styles.slot}>
          <Text style={styles.slotLabel}>Arbitre</Text>
          {team.referee
            ? <View style={styles.chips}>{chip(team.referee, () => setTeam((t) => ({ ...t, referee: null })))}</View>
            : (
              <Pressable onPress={() => setPicker({ kind: 'referee' })} accessibilityRole="button">
                <Text style={styles.slotEmpty}>Choisir un arbitre…</Text>
              </Pressable>
            )}
        </View>
      </ScrollView>

      <View style={styles.footer}>
        {!result.valid && <Text style={styles.error}>{result.errors[0]}</Text>}
        <Pressable disabled={!result.valid} onPress={save} style={[styles.cta, !result.valid && styles.ctaDisabled]} accessibilityRole="button">
          <Text style={styles.ctaText}>Enregistrer l'équipe</Text>
        </Pressable>
      </View>

      <Modal visible={!!picker} animationType="slide" transparent onRequestClose={() => setPicker(null)}>
        <View style={styles.modalWrap}>
          <View style={styles.modal}>
            <Text style={styles.modalTitle}>{picker && (picker.kind === 'pilot' ? picker.slot.label : PICKER_TITLES[picker.kind])}</Text>
            <FlatList
              data={options()}
              keyExtractor={(o) => `${o.cardId}:${o.rarity}`}
              ListEmptyComponent={<Text style={styles.empty}>Aucune carte de ce type. Ouvre des packs !</Text>}
              renderItem={({ item }) => {
                const rider = item.card.type === 'PILOT' ? RIDERS_BY_ID[item.card.subject] : null;
                return (
                  <Pressable onPress={() => choose(item)} style={styles.option} accessibilityRole="button"
                    accessibilityLabel={`Choisir ${item.card.name} ${RARITY_LABELS[item.rarity]}`}>
                    <Text style={styles.optionName}>{item.card.name} · {RARITY_LABELS[item.rarity]}{rider ? ` · ×${rider.cote.toFixed(1)}` : ''}</Text>
                    {item.card.effects.map((e, i) => <Text key={i} style={styles.optionEffect}>{describeEffect(e, item.rarity, BALANCE)}</Text>)}
                  </Pressable>
                );
              }}
            />
            <Pressable onPress={() => setPicker(null)} style={styles.close}><Text style={styles.closeText}>Fermer</Text></Pressable>

}
```

```markdown
# Guide du joueur — Super Fantasy Bike Trial

## Le principe

Avant chaque manche de Coupe du monde de trial, tu composes une équipe de six vrais pilotes. Quand la manche est terminée, tes pilotes marquent des points selon leurs résultats réels. Tes cartes ajoutent des bonus.

## Composer son équipe

- Six emplacements : Senior 26", Junior 26", Senior 20", Junior 20" et deux Elite Femmes différentes.
- Chaque emplacement reçoit une **carte pilote** que tu possèdes, de la bonne catégorie.
- Un pilote peut porter des **techniques** : 1 en Commune ou Rare, 2 en Épique, 3 en Légendaire.
- L'équipe peut aussi recevoir **2 équipements** et **1 arbitre**. Ces emplacements sont facultatifs.
- Une même carte ne sert qu'une fois par équipe. Tes cartes se réutilisent d'une manche à l'autre.
- Tu peux modifier ton équipe jusqu'au premier jour de la manche. Elle est ensuite verrouillée.

## Les points

- Points d'un pilote = points de classement × cote. Le 1er marque 100, le 2e 80, le 3e 65…
- La cote dépend du classement mondial : de ×1,0 pour le top 3 à ×2,5 au-delà du top 50. Un outsider bien placé rapporte gros.
- Ensuite, les effets de tes cartes s'appliquent dans cet ordre : bonus d'un pilote, bonus d'une catégorie, bonus d'équipe, puis points fixes.
- Le détail du résultat liste chaque effet déclenché et ce qu'il t'a rapporté.

## Les cartes

| Type | Où elle se place | Sur quoi elle agit |
|---|---|---|
| Pilote | un emplacement de sa catégorie | lui-même |
| Technique | sur un pilote | le pilote qui la porte |
| Équipement | emplacement d'équipe (2) | toute l'équipe ou une catégorie |
| Arbitre | emplacement d'équipe (1) | toute l'équipe |

Chaque carte existe en plusieurs raretés : **Commune**, **Rare**, **Épique**, **Légendaire**. Plus la carte est rare, plus son effet rapporte. Tous les pilotes n'ont pas de version Légendaire.

Les **légendes** sont des pilotes retraités : ils ne marquent pas de points de classement, mais leur effet rapporte à chaque manche. Un pilote n'a pas besoin de courir la manche pour être joué, mais un effet lié à son résultat ne se déclenche pas s'il est absent.

## Les packs

- **Pack de départ** : 10 cartes Communes pour composer une première équipe.
- **Pack du jour** : un pack gratuit par jour, 5 cartes dont au moins une Rare. Les packs ne s'accumulent pas : reviens chaque jour.
- **Garantie** : une Épique au moins tous les 10 packs, une Légendaire au moins tous les 60.

## Fragments et fabrication

- Un doublon se **recycle** en fragments (plus la carte est rare, plus elle en donne).
- Les fragments servent à **fabriquer** la carte et la rareté de ton choix, depuis la fiche de la carte.

## Saisons et classement

- Une saison = une année de Coupe du monde. Les dates des vraies manches pilotent le jeu : ouverture, verrouillage, résultats et archivage sont automatiques.
- Tu affrontes dix rivaux sur le classement cumulé de la saison. L'onglet Historique garde tes saisons passées.
```
